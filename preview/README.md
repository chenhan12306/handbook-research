# Preview assets

Images in this folder are **CSS approximation previews** rendered with Headless Chrome from `sample-note.html` and the repository root `theme.css`. They are **not** screenshots of the Obsidian desktop/mobile application.

Before submitting to the [Obsidian Community Themes](https://community.obsidian.md/) directory, capture a real in-app screenshot (recommended **512×288**, 16:9) and place it at the repository root as `screenshot.png`.
